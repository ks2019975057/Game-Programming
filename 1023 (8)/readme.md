 	   return result;

5. 포인터와 변수의 값 변경

    값 전달은 변수 값의 복사본이 전달되므로 함수 안에서 바꿔도 원본은 변하지 않지만

	2. 포인터를 이용하여 함수 안에서 플레이어의 체력을 10 감소시키는 함수를 작성하시오. 단, 체력 변수의 주소를 매개변수로 전달받도록 하시오.

	{
    	*hp -= 10;
	}

6. 게임 점수 계산 함수
게임에서 플레이어가 획득한 점수와 추가 점수를 입력받아 총점을 계산하는 함수를 작성하시오.

- 함수 이름: `calculateScore`
- 입력: 현재 점수 `score`, 추가 점수 `bonus`
- 반환값: 두 점수의 합
- 함수의 원형과 함수 정의를 작성하고, `main()` 함수에서 호출하는 예를 제시하시오.

#include <stdio.h>

int calculateScore(int score, int bonus);   // 함수 원형

int main(void)
{
    int score = 100;
    int bonus = 50;
    int total = calculateScore(score, bonus);
    printf("총점: %d\n", total);   // 총점: 150
    return 0;
}

int calculateScore(int score, int bonus)    // 함수 정의
{
    return score + bonus;
}
