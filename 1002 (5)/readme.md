## 음계와 피아노 건반
    컴퓨터상에서 기계적인 음을 표현하는 방법
    기계적인 음은 주파수를 이용하여 구분하고 표현하는데 음파의 주파수가 높으면 고음을, 낮으면 저음을 낸다.

    옥타브는 1:2의 음정 비를 가짐 1 옥타브가 올라갈 때 *2
    ex> 옥타브 2의 도(C)는 옥타브 1의 도(C, 32.7032)×2 = 65.4064로 계산

    pow() : 음계의 주파수 계산
    Beep(주파수 , 소리 지속시간) : 주파수와 시간을 입력해 소리 출력

    키보드의 숫자 키 입력에 있어서 scanf를 사용한다면 숫자 입력 후에 Enter키를 눌러야 해 음의 연결이 자연스럽지 못하기 때문에 Enter키가 필요 없는 getch를 이용.

    getch는 숫자 키를 문자로 입력받기 때문에 문자 '1'을 입력했을 경우 숫자 0 (배열의 첫 번째 첨자)으로 만들어주기 위해 원래의 값에서 49를 빼 주어야 한다.
