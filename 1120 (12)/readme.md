# 게임프로그래밍 12주차 수업내용 1120

Star Eater
로그라이크 슈팅 게임 (통칭 뱀서라이크)

여러 무기들로 자동 공격하고 레벨 업해서 플레이어를 성장시키는 슈팅 게임
다수의 일반 적, 특수 스킬을 지닌 소수의 특수 적, 마지막으로 여러 보스를 잡아서 클리어 하는 것이 목표

v1 - 현재까지 완료된 게임 파일 프롬프트 30개 이상 (기능 추가 예정)

v1 뱀서라이크 + 보스전 웹게임 프롬프트 모음 
사용 방법과 개요

v2 플레이어와 무기 및 적 수정, 엔딩 연출 추가

v3 성장 곡선 조정 및 ui 요소 추가



프롬프트 목록

P1~P70을 순서대로 AI에 입력하면 "우주의 작은 점이 별을 먹어 가장 강해지는" 뱀서라이크 + 보스전 웹게임(HTML, CSS, JavaScript)이 단계별로 완성됩니다.

사용 방법

각 프롬프트 앞에 "아래는 현재 코드야:" 와 지금까지의 코드를 붙여서 입력합니다. 첫 프롬프트(P1)에는 임시로 만든 기존 코드를 붙입니다.
프롬프트마다 나온 코드를 실행해 보고, 결과 파일을 단계마다 따로 저장합니다. 제출물이 결과물까지 포함이라서 단계별 버전이 증빙이 됩니다.
실행해 보고 생긴 문제는 "○○ 현상이 생겨, 원인과 해결법을 알려줘" 형태의 디버깅 프롬프트로 바꿔 끼워도 됩니다. 프롬프트는 30개를 넘어도 괜찮다는 조건이라 70개로 구성했습니다.
무기 수치는 모두 config.js 하나에서 읽도록 지시해 두었습니다. 밸런스를 바꿀 때는 수치만 고치면 됩니다.

확정된 설계

컨셉: 플레이어는 우주의 작은 점이고, 적을 처치하면 별 조각이 떨어지며 흡수하면 경험치가 됩니다. 플레이어의 크기는 변하지 않습니다.
무기 8종: 우주 먼지, 복사열, 위성, 운석, 대기, 혜성, 블랙홀, 플라즈마. 모두 레벨 1~5이고 5레벨 특수 효과는 없습니다.
진화: 레벨 없는 고정 수치. 두 무기가 모두 5레벨이면 진화 카드가 뜨고(양쪽 진화가 모두 있는 11쌍은 두 카드가 함께), 무기 하나당 진화는 1회입니다.
몹 체력 20을 밸런스 기준으로 삼았고, 몹 체력 20당 경험치 1입니다.
1단계. 분석·설계 (P1~P4)

현재 코드의 상태를 파악하고, 이후 모든 프롬프트가 기대는 구조와 규칙을 먼저 정합니다.

P1. 나는 대학교 3학년이고, HTML/CSS/JS로 "우주의 작은 점이 다른 별을 먹어치워 가장 강해지는" 뱀서라이크 + 보스전 웹게임을 임시로 만들었어. 아래 코드를 분석해서 구현된 기능, 구조적 문제, 개선 우선순위를 표로 정리해줘. [현재 코드 붙여넣기]

P2. 이 컨셉에 맞게 코어 루프를 세계관 용어로 재정의해줘. 적을 처치하면 별 조각이 떨어지고, 별 조각을 흡수하면 경험치가 되고, 레벨업하면 무기를 고르거나 강화해. 플레이어 크기는 변하지 않고 무기와 능력치로만 강해져. 현재 코드에서 빠진 요소와 추가할 요소를 우선순위별로 제안해줘.

P3. 현재 코드를 ES 모듈 기반(Game, Player, Enemy, Weapon, Boss, Spawner, Gem 등)으로 재구성하는 설계안과 파일 구조를 제안해줘. 각 클래스의 책임과, 수치를 한곳에서 관리하는 config.js의 구조도 포함해줘.

P4. 게임 상태(타이틀, 플레이, 레벨업 선택, 일시정지, 보스전, 게임오버, 클리어)를 상태 머신으로 설계하고, 상태 전환 조건과 각 상태에서 멈추거나 계속 도는 시스템을 표로 정리해줘.

2단계. 기반 시스템 (P5~P9)

무기와 몹이 올라갈 바닥을 먼저 깔고, 상태 전환까지 구현합니다.

P5. 게임 루프를 고정 타임스텝(fixed timestep)과 deltaTime 기반으로 개선하고, 탭 전환이나 창 포커스 이탈 후 돌아왔을 때 시간이 튀지 않게 처리해줘.

P6. 플레이어를 따라가는 카메라와 무한히 반복되는 우주 배경(별이 흐르는 패럴랙스 레이어 3개)을 구현해줘. 월드 좌표와 화면 좌표를 변환하는 함수는 따로 분리해줘.

P7. WASD와 방향키로 이동하는 Input 모듈을 만들어줘. 대각선 이동 속도를 보정하고 부드러운 가감속을 넣어줘.

P8. 적, 투사체, 별 조각이 수백 개일 때를 대비해 공간 해시 그리드로 충돌 판정을 최적화해줘. 원형 충돌체 기준이고, 질의 함수는 "이 위치 반경 안의 개체 목록" 형태로 공용으로 쓸 수 있게 해줘.

P9. P4에서 설계한 상태 머신으로 타이틀, 플레이, 레벨업 선택, 일시정지(P키), 게임오버, 클리어 화면 전환을 구현해줘. 레벨업 선택과 일시정지 중에는 게임 시간이 멈추고, 입력 이벤트는 현재 상태에서만 처리되게 해줘.

3단계. 경험치·레벨업 (P10~P12)

별 조각 흡수가 경험치가 되는 방식으로 확정된 부분입니다. 수치는 몹 체력 20당 경험치 1 기준입니다.

P10. 적을 처치하면 별 조각이 떨어지고, 별 조각을 흡수하면 경험치가 되는 시스템을 구현해줘. 별 조각은 작은(경험치 1, 반경 4px), 중간(5, 7px), 큰(20, 11px) 3종이고, 몹 체력 20당 경험치 1로 계산해서 드롭 종류를 정해줘. 플레이어 흡수 범위 60px 안에 들어오면 150px/s에서 시작해 초당 600씩 가속하며 끌려오고, 12px 이내에 닿으면 경험치로 변환돼. 흡수 범위는 나중에 패시브로 늘릴 수 있게 player.magnetRange 변수로 두고, 화면에 300개를 넘으면 가까운 별 조각끼리 합쳐서 한 단계 큰 조각으로 만들어줘. 필요 경험치는 round(5 × 1.25^(레벨-1)) 공식이고, 수치는 config.js에서 읽어와줘. 별 조각은 작은 노란색 별빛으로 그리고 끌려올 때는 꼬리 잔상을 남겨줘.

P11. 레벨업 시 게임이 멈추고 카드 3장 중 하나를 고르는 UI를 만들어줘. 카드는 무기 획득, 무기 강화(레벨 1~5)로 구성되고, 이미 5레벨인 무기는 카드 풀에서 제외해. 카드 풀 생성 함수를 따로 만들어 나중에 진화 카드를 가중치로 끼워 넣을 수 있게 해줘. 키보드(1, 2, 3)와 마우스로 선택 가능해야 해.

P12. 화면 상단에 경험치 바와 레벨, 하단 또는 좌측에 플레이어 체력바, 우측 상단에 생존 시간 타이머 HUD를 만들어줘. 경험치를 얻을 때 바가 부드럽게 차오르게 하고, 현재 보유한 무기 아이콘과 레벨을 작은 슬롯으로 표시해줘.

4단계. 무기 8종 (P13~P21)

모든 무기는 레벨 1~5이고, 피해량은 레벨이 올라도 줄어들지 않으며, 5레벨 특수 효과는 없습니다. 수치는 전부 config.js의 WEAPONS에서 읽습니다.

P13. 무기 공통 구조를 만들어줘. 모든 무기는 level(1~5), update(dt), 쿨타임 타이머를 가진 클래스로 만들고, 레벨별 수치는 config.js의 WEAPONS 객체에서 읽어와. 플레이어는 무기를 최대 6개까지 보유할 수 있고, 획득한 무기와 레벨은 HUD 슬롯에 표시돼. 레벨업 카드 풀은 보유 무기의 강화 카드와 미보유 무기의 획득 카드로 구성해줘.

P14. 우주 먼지. 쿨타임마다 가장 가까운 적에게 작은 투사체를 발사하는 무기를 구현해줘. 레벨 1~5의 피해량은 8, 9, 10, 11, 12, 투사체 수는 1, 1, 2, 2, 3개, 투사체 속도는 300, 330, 360, 390, 420px/s, 쿨타임은 1.00, 0.75, 0.60, 0.42, 0.30초야. 투사체가 2개 이상이면 0.05초 간격으로 순차 발사하고, 쿨타임 하한은 0.15초로 제한해줘. 투사체는 적 하나를 맞히면 사라지고, 화면 밖이나 사거리 500px를 넘으면 제거해줘.

P15. 복사열. 플레이어를 중심으로 한 원형 영역이 쿨타임마다 펄스를 내서 영역 안의 모든 적에게 피해를 주는 무기를 구현해줘. 레벨 1~5의 피해량은 5, 6, 7, 8, 9, 범위 반경은 60, 70, 80, 90, 100px, 쿨타임은 1.00, 0.90, 0.80, 0.70, 0.60초야. 영역은 플레이어 크기와 상관없이 중심에서 고정 반경이고, 반투명 주황색 원으로 그리며 펄스 순간에 밝아지게 해줘. 충돌은 거리 <= 반경 + 적 반지름으로 판정해줘.

P16. 위성. 플레이어 중심 반경 120px로 공전하는 중거리 소환물을 구현해줘. 무기를 얻으면 즉시 소환되고, 지속시간이 끝나면 사라진 뒤 그 시점부터 쿨타임이 지나면 다시 소환돼. 위성은 공격만 하고 적 본체나 적 투사체를 막지 않아. 레벨 1~5의 피해량은 8, 9, 10, 11, 12, 위성 수는 2, 2, 3, 4, 5개, 공전 속도는 100, 110, 120, 130, 140deg/s, 지속시간은 3.0, 3.5, 4.0, 4.5, 5.0초, 쿨타임은 5.0, 4.5, 4.0, 3.5, 3.0초야. 같은 위성이 같은 적을 0.5초 안에 다시 때리지 않게 하고, 위성은 360도 균등 간격으로 배치해줘. 크기는 8px이고, 소환과 소멸 때 0.3초 페이드를 넣어줘.

P17. 운석. 쿨타임마다 플레이어 주변 500px 안의 무작위 적을 골라 그 위치에 붉은 예고 원을 0.6초 동안 표시하고, 이후 운석이 떨어져 범위 안의 모든 적에게 피해를 주는 무기를 구현해줘. 레벨 1~5의 피해량은 25, 30, 35, 40, 45, 공격 범위 반경은 50, 55, 60, 65, 70px, 쿨타임은 4.0, 3.6, 3.2, 2.8, 2.4초, 한 번에 떨어지는 운석 수는 1, 1, 2, 2, 3개야. 여러 개일 때는 서로 다른 적을 고르고(적이 부족하면 중복 허용) 0.15초 간격으로 순차 낙하시켜줘. 대상이 없으면 0.3초 뒤에 다시 시도하고, 착탄 시 폭발 파티클과 약한 화면 흔들림을 넣어줘.

P18. 대기. 플레이어를 감싸는 보호막을 만들어줘. 피해를 한 번 받으면 그 피해를 완전히 무효화하고 깨지며, 접촉 피해와 적 투사체와 보스 공격 모두 막을 수 있어. 무기를 얻으면 즉시 보호막이 생성되고, 깨진 시점부터 쿨타임이 지나면 다시 생성돼. 레벨 1~5의 쿨타임은 20, 17, 14, 11, 8초이고, 쿨타임 하한은 4초야. 보호막이 깨진 직후 0.5초 동안은 무적이야. 보호막은 반투명 하늘색 원으로 그리고, 깨질 때 파티클을, 재생성될 때 퍼지는 연출을 넣어줘. 쿨타임 중에는 플레이어 아래에 원형 게이지를 표시해줘.

P19. 혜성. 쿨타임마다 가장 가까운 적 방향으로 큰 투사체(반경 12px, 속도 500px/s)를 발사하고, 투사체는 경로의 모든 적을 관통하며 사거리 800px에서 사라지는 무기를 구현해줘. 같은 투사체가 같은 적을 중복 타격하지 않게 기록해줘. 레벨 1~5의 피해량은 20, 24, 28, 32, 36, 투사체 수는 1, 1, 2, 2, 3개, 쿨타임은 3.0, 2.8, 2.6, 2.4, 2.2초야. 여러 발일 때는 10도 간격의 부채꼴로 동시에 발사하고, 흰색에서 하늘색으로 번지는 긴 꼬리를 그려줘.

P20. 블랙홀. 쿨타임마다 플레이어 주변 500px 안에서 반경 내 적이 가장 많은 지점에 블랙홀을 설치하고, 지속시간 동안 범위 안의 적을 80px/s로 중심 쪽으로 끌어당기며 0.5초마다 피해를 주는 무기를 구현해줘. 적은 중심에서 12px 지점까지만 끌려와서 멈추고, 지속시간이 끝나면 블랙홀이 사라진 뒤 쿨타임이 시작돼. 레벨 1~5의 틱당 피해량은 4, 5, 6, 7, 8, 범위 반경은 90, 100, 110, 120, 130px, 지속시간은 2.0, 2.5, 3.0, 3.5, 4.0초, 쿨타임은 8.0, 7.5, 7.0, 6.5, 6.0초야. 적이 없으면 0.3초 뒤에 다시 시도하고, 검은 원과 보라색 회전 링으로 그려줘.

P41. 궤도 복사 (복사열 + 위성). 복사열이 궤도 복사로 진화해. 플레이어 중심의 단일 영역이 반경 50px의 작은 영역 4개로 갈라져서 플레이어 주위 반경 110px를 120deg/s로 상시 공전해. 4개는 360도 균등 간격이고, 동시에 쿨타임 0.6초마다 펄스를 내서 피해 13을 줘. 영역이 겹쳐도 한 적은 한 펄스에 한 번만 피해를 받아. 반투명 주황색 원으로 그려줘.

P42. 복사 광선 (복사열 + 혜성). 복사열이 복사 광선으로 진화해. 원형 펄스가 사라지고, 쿨타임 0.8초마다 가장 가까운 적 방향으로 길이 100px, 폭 24px의 레이저를 0.15초 동안 발사해. 피해 30이고 경로의 모든 적을 한 번씩 관통해. 흰색에서 주황색으로 번지는 빔으로 그려줘.

위성 계열

위성 5레벨 기준: 피해 12, 위성 5개, 공전 140deg/s, 지속시간 5.0초, 쿨타임 3.0초, 공전 반경 120px. 위성도 4개 중 하나만 고를 수 있습니다.

P43. 인력 위성 (위성 + 블랙홀). 위성이 인력 위성으로 진화해. 위성 5레벨 기본 성능은 그대로이고, 접촉 피해가 12에서 18로 늘어. 활성 위성 반경 50px 안의 적을 해당 위성 쪽으로 30px/s로 약하게 끌어당기고, 위성에 닿은 적은 더 끌지 않아. 보스는 끌어당김 면역이야. 위성 주변에 옅은 보라색 원을 표시해줘.

P44. 먼지 위성 (위성 + 우주 먼지). 위성이 먼지 위성으로 진화해. 위성 5레벨 기본 성능은 그대로이고, 활성 위성마다 1.5초에 한 번 가장 가까운 적(사거리 400px)에게 우주 먼지탄을 발사해. 먼지탄은 피해 9, 속도 400px/s이고 적 하나를 맞히면 사라져.

P45. 방전 위성 (위성 + 플라즈마). 위성이 방전 위성으로 진화해. 위성 5레벨 기본 성능은 그대로이고, 활성 위성마다 3.0초에 한 번 가장 가까운 적(사거리 400px)에게 플라즈마를 발사해. 피해 7, 연쇄 4(총 타격 수), 튀는 거리 100px이고 같은 발동에서 한 적은 한 번만 맞아. 위성에서 적까지 보라색 번개선을 0.15초 동안 표시해줘.

P46. 열위성 (위성 + 복사열). 위성이 열위성으로 진화해. 위성 5레벨 기본 성능(접촉 피해 12)은 그대로이고, 위성에 부딪힌 적은 3.0초 동안 0.5초마다 화상 피해 4를 입어. 화상 중에 다시 닿으면 지속시간만 3.0초로 갱신되고 중첩되지 않아. 화상 중인 적에게 주황색 불꽃 파티클을 표시해줘.

플라즈마 계열

플라즈마 5레벨 기준: 피해 22, 연쇄 5, 쿨타임 1.4초, 튀는 거리 150px. 플라즈마도 4개 중 하나만 고를 수 있습니다.

P47. 응집 플라즈마 (플라즈마 + 블랙홀). 플라즈마가 응집 플라즈마로 진화해. 피해가 22에서 33으로 늘고 연쇄 5, 쿨타임 1.4초는 그대로야. 한 번 발동에서 맞은 적들은 맞은 적들의 중심점 쪽으로 40px 끌려가며 서로 뭉쳐(0.3초에 걸쳐). 보스는 끌어당김 면역이야.

P48. 플라즈마 레이저 (플라즈마 + 혜성). 플라즈마가 플라즈마 레이저로 진화해. 기본 성능(피해 22, 연쇄 5, 쿨타임 1.4초)은 그대로이고, 연쇄 경로(플레이어에서 첫 대상, 그다음 대상으로 이어지는 선분들)에 폭 16px의 레이저가 1.5초 동안 남아 0.5초마다 선분에 닿은 적에게 피해 4를 줘. 레이저가 겹쳐도 한 적은 0.5초에 한 번만 피해를 받아. 보라색과 흰색 빔으로 그리고 남은 시간이 줄수록 옅어지게 해줘.

P49. 견인 플라즈마 (플라즈마 + 위성). 플라즈마가 견인 플라즈마로 진화해. 피해가 22에서 33으로 늘고 나머지 기본 성능은 그대로야. 맞은 적의 80px 안에 활성 위성이 있으면 그 적은 2초 동안 가장 가까운 위성 쪽으로 60px/s로 끌려다녀. 활성 위성이 없으면 끌어당김 효과는 없고, 보스는 면역이야.

P50. 유도 플라즈마 (플라즈마 + 우주 먼지). 플라즈마가 유도 플라즈마로 진화해. 피해가 22에서 33으로 늘고 나머지 기본 성능은 그대로야. 맞은 적은 2초 동안 표식이 붙고, 표식 적의 150px 안에 있는 우주 먼지 계열 투사체는 그 적을 향해 초당 최대 180도까지 회전하며 유도돼. 표식 적이 죽으면 가장 가까운 다른 표식 적을 따라가. 표식 적에게 작은 보라색 고리를 표시해줘.

대기 계열

대기 5레벨 기준: 보호막 쿨타임 8초, 깨진 직후 0.5초 무적. 아래 진화는 모두 보호막이 깨지는 순간 한 번 발동하고, 한 무기는 4개 중 하나만 고를 수 있습니다.

P51. 중력 방벽 (대기 + 블랙홀). 대기가 중력 방벽으로 진화해. 보호막이 깨지는 순간 반경 400px 충격파가 퍼져서 범위 안의 모든 적에게 피해 200을 주고, 적을 플레이어 기준 바깥쪽 화면 가장자리까지 0.5초에 걸쳐 밀어내. 보스는 밀림 면역이지만 피해는 받아.

P52. 별똥 방벽 (대기 + 혜성). 대기가 별똥 방벽으로 진화해. 보호막이 깨지는 순간 15도 간격으로 360도 사방에 혜성 24발을 발사해. 각 혜성은 피해 100, 속도 500px/s, 사거리 800px이고 경로의 모든 적을 관통하며 같은 혜성이 같은 적을 중복 타격하지 않아.

P53. 유성 방벽 (대기 + 운석). 대기가 유성 방벽으로 진화해. 보호막이 깨지는 순간 플레이어 주변 400px 안의 적 위치에 운석 8발이 0.1초 간격으로 떨어져. 예고 0.3초 후 착탄하고 각 운석은 피해 25, 반경 60px야. 적이 8마리보다 적으면 중복을 허용하고, 적이 없으면 플레이어 주변 무작위 위치에 떨어져.

P54. 쌍성 방벽 (대기 + 위성). 대기가 쌍성 방벽으로 진화해. 보호막이 깨지는 순간 위성이 쿨타임 중이어도 즉시 소환하고, 위성 5개를 추가해 3.0초 동안 10개(360도 균등 배치)로 유지해. 3초가 지나면 추가된 5개는 사라지고, 기본 위성은 원래의 지속시간과 쿨타임 규칙을 따라.

6단계. 몹과 보스 (P55~P58)

몹 12종과 보스 6종은 AI가 세계관(우주의 천체들)에 맞춰 제안하고 구현한 결과를 기준으로, 실제 게임에 들어간 내용에 맞게 다시 쓴 프롬프트입니다. 수치는 config.js에서 바꿀 수 있습니다.

P55. 이 게임의 몹을 세계관(우주의 천체들)에 맞게 설계하고 구현해줘. 기본 적, 스피드, 보호막, 탱커, 분열(+분열 조각), 반격, 돌진, 치유, 포식, 앵커, 사수 12종을 만들고, 각각 체력, 방어, 속도, 접촉 피해, 크기와 고유 행동(돌진 예고, 사수의 조준 사격, 반격 탄막, 분열 등)을 정해줘. 일반 몹의 기준 체력은 20이고, 처치하면 종류에 따라 크기가 다른 별 조각이 떨어져. 몹은 크기와 색으로 구분하고, 피격 시 흰색으로 깜빡이게 해줘.

P56. 플레이어 주변 화면 밖에서 몹이 생성되는 스포너를 만들고, 시간대별 웨이브 테이블을 config.js의 데이터로 관리해줘. 시간이 지날수록 몹 수, 속도, 체력이 늘어나는 난이도 곡선을 설계해줘. 화면 안의 몹이 300마리를 넘으면 생성을 멈춰줘.

P57. 2분(120초)마다 등장하는 중간 보스를 만들어줘. 분열체, 돌진체, 방벽체, 철갑체, 수정체 5종을 만들고 등장 순서는 매 판 무작위로 섞어줘. 등장 30초 전 경고, 10초 전 카운트다운, 등장 연출(경고 문구와 화면 흔들림), 화면 상단 체력바, 전용 아레나, 종류마다 다른 공격 패턴을 포함하고, 패턴 선택은 상태 머신으로 구현해줘. 보스는 넉백에 면역이고, 나온 순서가 뒤일수록 체력·피해·속도가 올라가게 해줘. 처치하면 큰 별 조각과 회복 구슬을 떨어뜨리고, 보스전 동안 일반 몹 생성량은 줄여줘.

P58. 중간 보스 5종을 모두 처치하면 최종 보스 심연의 블랙홀이 등장하게 해줘. 중간 보스보다 크고 강하며, 체력이 50% 이하가 되면 2페이즈로 전환(패턴 강화, 연출 변경)해. 처치하면 클리어 화면으로 이어지고, 클리어 화면에는 생존 시간, 처치 수, 도달 레벨을 보여줘. 플레이어가 죽으면 게임오버 화면으로 이어지게 해줘.

7단계. 완성도·품질 (P59~P67)

P59. 피격 플래시, 데미지 숫자 팝업, 화면 흔들림, 몹 사망 파티클, 보스 등장 연출 같은 타격감 이펙트를 추가해줘. 이펙트 강도는 config.js에서 조절할 수 있게 해줘.

P60. Web Audio API로 배경음악(BGM)과 효과음을 넣어줘. 외부 음원 파일 없이 오실레이터와 노이즈로 합성하고, 모든 소리는 하나의 Audio 모듈에서 재생 함수(play('hit') 형태)로 관리해줘. BGM은 평상시와 보스전 두 곡이고, 보스전에 들어가면 크로스페이드로 바뀌고 보스를 잡으면 평상시 곡으로 돌아와. 효과음은 무기 발사(무기마다 다른 음색), 적 피격과 처치, 별 조각 흡수(연속으로 먹으면 음이 올라감), 레벨업, 카드 선택, 대기 보호막 깨짐, 플레이어 피격, 보스 경고와 등장, 보스 처치, 게임오버, 클리어야. 같은 소리가 한 프레임에 수십 개 겹치지 않게 동시 재생 수와 재생 간격을 제한하고, 볼륨 슬라이더(BGM과 효과음 따로)와 음소거 토글(M키)을 넣어줘. 브라우저 정책상 첫 클릭 이후에 AudioContext를 시작하고, 설정은 localStorage에 저장해줘.

P61. localStorage로 최고 생존 시간, 최고 레벨, 누적 처치 수를 저장하고 타이틀 화면과 게임오버 화면에 표시해줘. 저장소를 못 쓰는 환경에서도 게임이 정상 동작하게 try/catch로 감싸줘.

P62. 터치용 가상 조이스틱과 반응형 캔버스 크기 조정을 구현해서 모바일에서도 플레이되게 해줘. 레벨업 카드와 일시정지 버튼도 터치로 조작할 수 있어야 해.

P63. 투사체, 몹, 별 조각, 파티클에 오브젝트 풀링을 적용하고 화면 밖 개체는 그리기에서 제외(컬링)해줘. 적용 전후의 FPS를 측정하는 방법도 알려줘.ㅏ

P64. 밸런스 테스트 모드를 만들어줘. 디버그 키로 켜면 체력이 무한한 더미 적을 두 가지 상황으로 생성해줘. 하나는 1마리, 하나는 4마리가 40px 안에 뭉친 상황이야. 선택한 무기나 진화 무기를 60초 동안 사용하고 총 피해량을 초당 평균으로 화면에 표시해서, 단일 대상 DPS와 밀집 DPS를 확인할 수 있게 해줘.

P65. 무기별 DPS와 진화 무기 DPS를 단일·밀집 상황에서 측정해서, 원본 5레벨 대비 진화의 몫(짝 무기 단독 DPS는 뺀 값)을 비교해줘. 너무 센 진화만 config.js 수치를 낮추고, 약한 진화는 올리지 않는 방식으로 조정안을 근거와 함께 제시한 뒤 적용하고 다시 측정해줘.

P66. 일시정지 중 타이머, 레벨업 선택 중 입력, 보스 사망 직후 충돌, 창 포커스 이탈, 위성과 블랙홀의 지속시간 중 레벨업, 대기 보호막이 깨진 직후 동시 피격 같은 버그 시나리오를 테스트 코드로 직접 재현해서 확인하고, 문제가 있으면 원인과 수정 내용을 알려준 뒤 고쳐줘. (결과: 레벨업 카드를 고르면 누르던 이동키가 풀리는 버그 1건을 수정했고, 나머지는 정상)

P67. 상수와 밸런스 수치가 전부 config.js에 있는지 확인하고 코드 전체를 리뷰해줘. 중복 코드 제거, 사용하지 않는 코드 정리, 주석 정리, 파일 구조 정리를 해줘.

8단계. 마무리 (P68~P70)

P68. GitHub Pages로 이 게임을 배포하는 과정을 처음부터 단계별로 안내해줘. 저장소 생성, 파일 올리기, Pages 설정, 배포 주소 확인, 모바일에서 접속해서 확인하는 방법까지 포함해줘.

P69. 제출용 README.md를 작성해줘. 게임 소개와 세계관, 조작법, 무기 8종과 진화 규칙 설명, 파일 구조, 사용 기술(HTML, CSS, JavaScript), 실행 방법, 배포 주소 자리, 스크린샷 자리를 포함해줘.

P70. 이 프로젝트의 개발 과정, AI 활용 방식(단계별 프롬프트 설계, 수치를 config.js로 분리해 반복 조정한 방식), 막혔던 부분과 해결 방법, 한계, 개선하고 싶은 점을 회고 형식으로 정리하는 걸 도와줘.

v2
P71. 배경과 플레이어 강조. 배경이 너무 단조로워. 별만 흐르는 지금 구조에 성운(색이 다른 부드러운 덩어리 여러 장)과 행성(고리 있는 것 포함 3종)을 패럴랙스 레이어로 추가하고, 플레이어의 위치와 시간에 따라 배경 색조가 천천히 바뀌게 해줘. 별은 반짝이게 해줘. 또 플레이어가 적과 구분이 잘 안 되니까, 푸른 빛과 회전하는 이중 고리, 검은 테두리가 있는 핵으로 눈에 확 띄게 만들어줘.

P72. 무기 MAX와 진화 보상. 무기를 5레벨까지 올려도 달라진 느낌이 없어. 5레벨이 되면 피해와 쿨타임이 확실히 좋아지고(수치는 config.js의 balance에서 조절), MAX 배너와 파티클이 뜨게 해줘. 진화 무기는 그보다 더 강하게(피해 +90%, 쿨타임 -20%) 만들고, 진화 순간에 링 여러 겹, 화면 섬광, 화면 흔들림, 전용 배너를 넣어줘. 진화한 뒤에는 금빛 외곽 고리와 반짝이는 입자가 계속 나오게 하고, 진화 카드 설명의 피해 숫자도 새 배율에 맞춰 자동으로 바뀌게 해줘.

P73. 난이도 상향. 적이 너무 적고 약해. 스폰율을 높이고, 시간이 지날수록 체력 성장과 방어력이 함께 커지게 해줘. 방어력은 분당 증가하되 최대치를 두고, 특수 적 비율도 올려서 진화 무기가 없으면 힘들게 맞춰줘. 수치는 모두 config.js에서 읽게 해줘.

P74. 이벤트 웨이브. 보스 전까지 잡몹 잡기만 반복돼서 단조로워. 보스가 없는 동안 일정 간격(38~55초)으로 이벤트가 터지게 해줘. 기본 적이 한쪽에서 무더기로 오는 "적 떼 습격", 사방에서 좁혀 오는 "포위", 특수 적 한 종이 여러 마리 몰려오는 "압박" 세 가지야. 이벤트 전에 경고 문구와 붉은 섬광을 띄우고, 같은 이벤트가 연속으로 나오지 않게 하고, 보스 직전 18초 동안은 쉬게 해줘.

P75. 보스 추가 패턴. 보스가 단조로워. 보스 6종 각각에 기존 패턴과 겹쳐 돌아가는 고유 패턴과 탄막을 추가해줘. 분열체는 별똥 폭우와 꽃잎 고리, 돌진체는 돌진 중 꼬리 탄과 탄 장막, 방벽체는 쌍나선, 철갑체는 틈이 있는 탄 장막과 유도 포격, 수정체는 파편 부채꼴과 2페이즈 십자 레이저, 블랙홀은 중력 맥동과 회전 팔이야. 체력이 50% 이하가 되면 패턴 간격이 짧아지고 탄이 늘게 해줘.

P76. 엔딩 연출. 최종 보스 블랙홀을 잡으면 바로 클리어 화면으로 넘어가지 말고, 남은 적과 탄을 지운 뒤 배경(별, 성운, 행성)이 플레이어에게 빨려 들어가면서 검은 배경에 플레이어만 남게 해줘. 그 위에 "우주의 모든 별을 먹었다" 문구를 띄우고, 화면이 어두워진 뒤 기존 클리어 화면으로 이어지게 해줘.

v3
P77. 성장 곡선 조정. 레벨업이 너무 빨라. 레벨업 필요 경험치를 완만한 2차 곡선으로 바꿔서 초중반은 2배 넘게 느리게, 후반은 지금과 비슷하게 해줘. 성장이 느려진 만큼 적의 체력 성장, 방어력 성장, 스폰 증가량도 함께 낮춰서 밸런스를 맞춰줘.

P78. MAX 특수 효과. 무기를 5레벨까지 올렸을 때 피해와 쿨타임만 좋아지면 밋밋해. 무기마다 그 무기의 특징을 살린 5레벨 전용 효과를 추가해줘. 우주 먼지는 관통 대형탄, 복사열은 화상, 위성은 넉백, 운석은 잔불 장판, 대기는 깨질 때 충격파, 혜성은 끝 폭발, 블랙홀은 소멸 폭발, 플라즈마는 연쇄 증가와 감전이야. 진화하면 진화 효과로 대체되게 하고, 레벨업 카드에 MAX 보너스를 표시해줘.

P79. 무기 아이콘. 왼쪽 위 무기 칸에 우, 혜, 플 같은 글자 대신 무기의 특징을 살린 그림을 그려줘. 캔버스 벡터로 그리고, 화면이 좁으면 칸 크기가 자동으로 줄게 해줘.

P80. 슬롯 확장과 리롤. 무기 슬롯 제한을 6개에서 8개로 늘려 8종을 모두 쓸 수 있게 해줘. 대신 레벨업 카드 화면에 카드를 다시 뽑는 리롤 버튼(R 키)을 넣고, 한 판에 1회만 쓸 수 있게 해줘. 횟수는 config.js에서 바꿀 수 있게 해줘.

P81. 디버그 실험실. ?debug=1에서 Q 키로 무기와 진화 무기를 바로 시험할 수 있는 실험실을 만들어줘. 열면 적 스폰과 보스 타이머를 멈추고 무적으로 만들어줘. 체력이 무한이고 움직이지 않는 허수아비를 사방에 8마리, 한곳에 뭉쳐서 4마리 세우는 키와 치우는 키를 넣어줘. 무기를 고르고 레벨을 올리거나 내리고(없으면 추가, 1레벨에서 내리면 제거), 진화를 하나씩 바꿔 적용하는 키도 넣어줘. 무기 전부 MAX와 전부 제거 키도 넣어줘. 패널에는 선택한 무기, 레벨, 진화 이름과 최근 5초 허수아비 DPS를 표시해줘. WASD와 겹치지 않는 키를 쓰고 사용법은 README에 적어줘.
