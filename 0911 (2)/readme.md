## 입력 버퍼 비우기
    c언어에서 scanf로 입력받다가 입력버퍼가 다 비워지지 않아서 문자입력 받는게 안되는 경우가 생김.
    
    #include <stdio.h>
    
        int main()
        {   char string[20];        
            char c;        
            
            scanf("%s", string);        
            scanf("%c", &c);        
            
            printf("%s\n", string);        
            printf("!!%c!!\n", c);        
            
            return 0;
        }
    

    문자열만 입력받고 프로그램이 끝나버림.

| 번호 | 해결 방법 | 설명 |
| :---: | :--- | :--- |
| **1** | `getchar();` | 간단하게 버퍼에 남은 문자를 읽어 처리 |
| **2** | `fflush(stdin);` | VC(Windows)에서만 동작 (GCC 미지원) |
| **3** | `tcflush(0, TCIFLUSH);` | 0번 디스크립터 비우기 유닉스 계열 터미널 전용 함수 |
| **4** | `rewind(stdio);` | 매개변수로 들어온 스트림 초기화 |
| **5** | `__fpurge(stdin);` | 리눅스 전용 함수 (`stdio_ext.h` 필요, 비표준) |
| **6** | `fgets(string, sizeof(string), stdin);' | 문자열 입력을 fgets로 받음, 다음 줄에 string[strlen(string)-1] = '\0'; 로 강제로 널문자를 넣어줘야함 |
| **7** | `scanf("%*c", c);` | %*c는 입력을 받되 저장하지 않고 버림 (비어있는 '\n` 제거) |
| **8** | `scanf("%c", &c);를 scanf(" %c", &c); 로` | `%c` 앞에 공백을 추가해 white space를 구분자로 인식 |

## ASCII code & scan code
    아스키 코드 : 컴퓨터 내부에서 문자를 처리(또는 전송)하기 위한 일종의 규칙으로, 문자에 대해서 미리 약속한 코드 값을 의미
    스캔 코드 : 키보드 각각의 키(key)에 대한 코드 값을 의미 
    
    일반적으로 스캔 코드는 확장키 코드를 말함.
    2바이트로써 상위 바이트는 스캔 코드, 하위 바이트는 아스키 코드로 구성.
    확장키 코드란 1 byte에 해당하는 256개의 아스키코드로 나타낼 수 없는 키 
    ex> 화살표 키, Home, End, Page Up, Page Down 등

## 방향키를 통한 이동
    방향키의 scan code를 이용해 상, 하, 좌, 우 로 이동
    switch문으로 키 입력을 받고 이동을 결정

| 화살표 키 | 스캔 코드 (10진수) | x의 변화 | y의 변화 |
| :---: | :---: | :---: | :---: |
| 상 (↑) | 72 | 없음 | y--; |
| 하 (↓) | 80 | 없음 | y++; |
| 좌 (←) | 75 | x--; | 없음 |
| 우 (→) | 77 | x++; | 없음 |

## 사각형 그리기
    확장 완성형 코드(─, │, ┌, ┘ 등)를 연속적으로 사용하여 사각형을 표시
| 기호 | 확장 완성형 코드 (10진수) |
| :---: | :---: |
| ┌ | 0xa3 (163) |
| ┐ | 0xa4 (164) |
| ┘ | 0xa5 (165) |
| └ | 0xa6 (166) |
